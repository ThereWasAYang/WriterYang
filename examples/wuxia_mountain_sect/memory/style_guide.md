# Style Guide

## Overall Style

中文武侠长篇，语言清晰克制，重视动作的因果、门派礼法和人物心理。避免过度堆砌古风词，避免现代网络口吻。

## Prose

- 句子以中短句为主，关键场面可使用较长句营造气势。
- 动作描写要能看出招式方向、距离、节奏和代价。
- 情绪表达尽量落在动作、停顿、称呼和礼数变化上。

## Dialogue

- 长辈说话稳重，不轻易解释全部信息。
- 同辈对白可有锋芒，但不使用现代吐槽语。
- 门派场景中注意称谓：掌门、师叔、师兄、师姐、外门、内门。

## Must Avoid

- 不要写成修仙体系。
- 不要让主角突然获得压倒性武力。
- 不要让角色在没有证据时直接说出隐藏真相。
- 不要在正文中出现“根据设定”“本章目标”“隐藏真相”等工作区语言。
